# V1-C Beta 内测部署说明

## 这是什么版本
从 V1-C 个人工作台升级来的第一个内测版。所有新增能力在右下角悬浮按钮「V1-C Beta 内测台」里，**不破坏原有 V9 界面**。

## 访问方式
线上地址：<https://phd-soroszhang.github.io/guoan-academic-workbench/>
首次进入后，右下角应该看到深蓝色悬浮按钮。

## 内测者操作清单
1. 打开页面，登录（密钥由作者分发）。
2. 点右下角「V1-C Beta 内测台」。
3. 先勾选顶部「学术使用协议」。
4. 依次点 10 个按钮：
   - **跑内置评测**：应看到 7/7 或 6/7 通过（DOI 在线校验受网络影响）。
   - **领域风控自检**：样例含"分裂国家/武装政变"，应返回 block。
   - **DOI 校验**：示例假 DOI 应被识别为 dead 或 unchecked。
   - **120维静态扫描**：粘贴任意一段，看命中数。
   - **证据缺口**：默认样例素材不足，应返回缺口。
   - **三档清洗样例**：看三档提示词差异。
   - **审计链校验**：应返回 ✅ 完整。
   - **配额状态**：返回当天用量。
   - **加载专题**：列出 5 个专题，展示海上通道上下文块。
   - **加密导出**：设密码后下载一个 JSON 文件。

## 本版故意没做的事（不要当 bug 报）
- 实时期刊排版预览、SVG 矢量图嵌入：下一版。
- 多人/团队/邀请码：需要后端，本版是单机版。
- Docker：本站是纯静态 GitHub Pages，不需要。
