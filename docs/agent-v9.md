# 内置学术 Agent（V9）

工作台现在自己就能干活：文献检索、精读、选题评估、大纲、写作清洗、审稿、参考文献，全部在页面内执行，不再需要把 Prompt 复制到别的平台。

V8 的全部资产原样保留：17 个业务模块、导师库、就业导航、理论术语库、12 维选题、17 套主题、回收站、多项目隔离、本地存储。

## 与 V8 的差别

| 旧 | 现在 |
| --- | --- |
| 只有「AI技能库」说明页，点不了任何东西 | 侧栏 11 个 Agent 入口，点开是参数面板，提交即执行 |
| 文献靠手工到知网、Google Scholar 抄 | OpenAlex / Crossref / Semantic Scholar / Zotero 并行检索，跨库去重排序 |
| 一次只能做一件事 | 一句目标 → 3–8 步流水线，关键处停下问人，可断点续跑 |

## 第一次使用

1. 侧栏「内置学术 Agent」→「设置」：填提供方、Base URL、模型名、API Key。
   默认 DeepSeek（`https://api.deepseek.com/v1`），也支持 GLM / Qwen / 任意 OpenAI 兼容端点，或勾选本地 Ollama。
2. 礼貌池邮箱默认已填，OpenAlex / Crossref 会因此给更高配额。
3. 点「测试连通」确认检索源与 Zotero 状态。

**不配模型也能用**：跨库检索（需自行填写英文检索词，否则中文主题会跳过国际库以免返回噪声）、Zotero 取用、中文库链接跳转。其余生成类任务需要模型。

## 自主流水线

侧栏「自主目标下达」写一句话，例如：

> 围绕海上通道排他性治理的棘轮效应，检索近五年英文文献，做选题评估，生成适配《太平洋学报》的大纲，再跑一遍 120 维审稿

Agent 拆成有序任务链执行，每步产出作为下一步上下文注入；遇到理论框架、案例范围这类关键学术选择会停下来让你选；关掉页面后点「断点续跑」可接上。

## 合规边界（明确不做）

- **知网 / 万方 / 维普 / 国家哲社文献中心不爬取**：这些库无公开检索 API 且条款禁止程序化抓取，工作台只生成高级检索式与跳转链接，由你在自己登录态下取用。
- **不代下全文**：只给题录、摘要、DOI、开放获取链接。
- **不编造文献**：检索结果只来自真实接口，格式化时缺失字段标「待补」。

## 技术说明

- 内核位于 `js/agent-core/`，30 个 ES 模块，六层：配置与存储（IndexedDB）、网络（按域名令牌桶限流 + 缓存 + 429/5xx 退避）、连接器、去重打分、业务模块、调度编排与 UI。
- 必须经 HTTP(S) 访问，`file://` 双击打开会因 ES Module 被浏览器拦截而白屏。
- 本地 Zotero API 需在 Zotero 7「设置 → 高级」勾选「允许本机其他应用与 Zotero 通信」；若 HTTPS 页面访问 `http://localhost:23119` 被拦，改用「粘贴 Zotero 导出 JSON」模式。
- Semantic Scholar 未认证额度约 2 请求/秒，模块内已单独限流，可在设置里填 S2 Key 提升。
