SecScholar 学术工作台

面向国家安全学 / 国际关系 / 公共管理方向研究者的纯前端写作助手。数据存在你自己浏览器里，不上传服务器。

快速上手

  1. 打开工作台首页，输入访问密钥进入。
  2. 在主界面选择一个论文任务类型（选题 / 大纲 / 文献 / 写作 / 返修 / 格式 / 审稿）。
  3. 右下角点「V1-C Beta 内测台」，先勾选学术使用协议。
  4. 建议先点「跑内置评测」确认环境正常。

FAQ

Q：我的论文会上传到服务器吗？
A：不会。所有稿件、文献、批注存在你浏览器的 localStorage 里；导出包可选密码加密。

Q：DOI 校验显示"未核验"是什么意思？
A：当前网络无法访问 doi.org，不代表这个 DOI 是假的，只是没在线验证过。导出前请人工核对。

Q：怎么备份我的研究空间？
A：Beta 面板里点「备份导出」，会下载一个 JSON 文件。换电脑时用「导入备份」还原。

Q：能直接把输出当论文交吗？
A：不能。工具只做辅助，所有内容必须你自己核验，否则学术不端。
