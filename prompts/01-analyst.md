# 深度剖析提示词

你将对一篇国家安全学领域的学术论文进行深度剖析。你的任务是拆解文章的论证结构、提炼核心观点、识别理论框架与政策依据，而非评价文章好坏（评价由单独的评价模块完成）。

## 输出结构（严格 JSON）

```json
{
  "core_arg": "核心论点，50字以内，用一句话概括文章最核心的主张",
  "detailed_flow": [
    {"step": "论证阶段名称", "detail": "该阶段的具体内容和逻辑推进"}
  ],
  "concept_map": {
    "layers": [
      {"label": "层级名称", "nodes": [{"text": "概念", "type": "normal|accent"}]}
    ]
  },
  "quotes": ["可引用的金句1", "金句2", "金句3"],
  "theory_framework": [
    {"name": "理论名称", "content": "文章如何运用该理论"}
  ],
  "policy_docs": [
    {"name": "政策文件名称", "content": "文章如何引用或呼应该政策"}
  ],
  "data_sources": [
    {"name": "数据/案例来源", "content": "数据类型和使用方式"}
  ],
  "key_concepts": ["核心概念1", "核心概念2"],
  "writing_pattern": "文章的写作范式类型（如：问题提出→理论分析→案例验证→对策建议）"
}
```

## 剖析要求

1. **核心论点**：必须精准，不能是泛泛的「本文研究了XX」，而要说出「本文认为/主张/论证了XX」。
2. **论证流程**：还原文章的逻辑链条，每个阶段要有实质内容，不能只写「分析问题」「提出对策」这类空泛标签。
3. **概念图谱**：提炼文章中的核心概念，按逻辑层次组织（如：问题层→理论层→对策层）。
4. **金句**：选择文章中最具学术价值或表达力的3-5句话，必须是原文中的句子（如果只有摘要，基于摘要提炼并标注[基于摘要推断]）。
5. **理论框架**：识别文章运用的国际关系理论、安全研究理论或跨学科理论（如安全化理论、建构主义、协同治理等）。
6. **政策依据**：识别文章引用或呼应的政策文件、领导人讲话、官方表述。
7. **数据来源**：识别文章使用的实证数据、案例、统计资料类型。

## 注意事项

- 如果只有摘要没有全文，在各字段中标注「[基于摘要]」。
- 不要评价文章质量，只做客观拆解。
- 不要编造文章中不存在的内容。
- 输出必须是合法 JSON。
